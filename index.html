$ values in thousands. Returns are total returns (dividends reinvested). 5-year total return is annualized; its liquid total is value-weighted over funds with 5 years of history. Illiquid returns (gray) are your assumed annual returns. Prices are end-of-day closes from Tiingo; an "As of" time (ET) means the price is a newer quote from Yahoo Finance, used until Tiingo catches up.

Subclasses for equities

Returns are value-weighted averages. Gray returns come only from illiquid assets' assumed annual returns, which are used for both the YTD and 5-year columns; funds without 5 years of history are left out of the 5-year average. Holdings with no asset class set are grouped under "Unclassified" — set the class on the Setup tab.

Upload a file

Download the Excel template (it's pre-filled with your current holdings), change the units or values, add rows for anything new, save, and upload it. CSV files work too. Rows match by ticker (liquid) or by name (illiquid). Anything not in the file stays as it is. You'll see a preview before anything is saved.
